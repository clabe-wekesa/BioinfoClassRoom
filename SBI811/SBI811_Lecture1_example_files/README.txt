SBI 811 - Lecture 1 Example Files
=================================

These are synthetic teaching files for Linux command-line practice.

Project contents
----------------
data/raw/
    sample01_R1.fastq
    sample01_R2.fastq
    sample01_R1.fastq.gz
    sample01_R2.fastq.gz

reference/
    genes.fasta
    annotation.gff

results/
    gene_counts.tsv

Suggested uses
--------------
- ls, pwd, cd, head, tail, cat, less, wc
- grep FASTA headers or annotation terms
- grep/awk GFF feature types and coordinates
- cut columns from gene_counts.tsv
- sort expression counts
- combine commands with pipes
- redirect selected output to new result files

All sequences and annotations are artificial and are intended only for teaching.
