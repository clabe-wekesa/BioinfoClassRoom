# SBI 811–812: Computational Bioinformatics

Course materials, practical exercises, datasets and supporting resources for two Master of Science in Bioinformatics courses:

| Course | Title | Main focus |
|---|---|---|
| **SBI 811** | **Computer Programming in Bioinformatics** | Linux, Bash, Git, GitHub, Python, AI-assisted programming and bacterial RNA-seq analysis |
| **SBI 812** | **Machine Learning in Bioinformatics** | Data preparation, exploratory analysis, machine-learning methods, model evaluation and biological applications |

## About this repository

This repository provides a shared learning environment for developing practical computational skills in bioinformatics. The materials emphasize hands-on problem solving, reproducible analysis and responsible use of artificial intelligence.

Students will use the repository to:

- access lecture notes and practical instructions;
- download example biological datasets;
- obtain starter scripts and exercises;
- practise version control using Git and GitHub;
- submit selected practical assignments; and
- develop reproducible bioinformatics projects.

## SBI 811: Computer Programming in Bioinformatics

SBI 811 introduces programming to students with no previous programming experience. The course uses biological problems to teach foundational computing concepts and culminates in a practical bacterial RNA-seq analysis.

### Topics

- Linux command-line fundamentals
- Bash commands, pipes, redirection and scripting
- Git and GitHub
- Python variables, data types and operators
- Conditions, loops and collections
- Functions, debugging and testing
- Reading FASTA, FASTQ, GFF and tabular files
- Responsible AI-assisted programming
- Reproducible bacterial RNA-seq analysis using BOTAS

### Course format

- **Duration:** 10 weeks
- **Contact time:** 3 hours per week
- **Entry level:** No previous programming experience required

## SBI 812: Machine Learning in Bioinformatics

SBI 812 introduces the use of machine-learning methods for analysing biological data. Course materials will cover the preparation, exploration, modelling and evaluation of bioinformatics datasets using Python-based tools.

### Topics

- Data manipulation with `pandas`
- Data exploration and visualization
- Preparing biological data for machine learning
- Supervised and unsupervised learning
- Model training and evaluation
- Overfitting, generalization and data leakage
- Interpretation of machine-learning results
- Responsible use of AI in computational research

## Responsible use of artificial intelligence

AI tools are integrated into the courses as learning and programming assistants. Students may use AI when permitted for a particular activity, but remain responsible for the correctness, reproducibility and biological validity of all submitted work.

The guiding principle is:

> **AI may generate code, but the student must understand, test, verify and defend it.**

Students must disclose material AI assistance and must not upload confidential, identifiable, clinical or unpublished research data to unauthorized AI services.

Replace `USERNAME` with the repository owner's GitHub username. Course-specific instructions will be provided inside the relevant directories.
